# 实验轨迹索引

每次运行保存在 `logs/<run_id>/`，编号不可复用。

- `manifest.json` 保存命令、Git 提交及工作区状态、完整配置、任务 ID、模型和原始提示词哈希、种子设置、版本及作业号。
- `trace.jsonl` 按事件顺序保存任务文件哈希、初始观察与状态哈希、动作请求及回复、环境反馈和执行状态、反思与下一次尝试实际收到的记忆。
- `summary.json` 汇总每组首次与累计成功数、首次失败任务 ID、恢复数、模型调用和输入输出词元数。恢复分母为该组首次失败数。分母为零时恢复率记为不适用。
- `inference_seconds` 为 llama.cpp 报告的 prompt 与 decode 耗时之和，包括反思。GPU 全部卸载时这是模型在 GPU 后端运行的经过时间，包含服务开销。另保留实际 GPU 分配时长用于 30 GPU 小时预算。

原始轨迹放在团队共享位置。PR 和 Notion 关联运行编号、配置、提交及共享位置。
